# Python Finance Projects

A progressive portfolio of quantitative finance projects built from scratch in Python.
Built by Matteo Nicotera — aspiring Quantitative Finance Master's student (ETH Zurich / Imperial College London).

---

## Projects

### 01 — Financial Basics
`01_compound_returns.py` · `02_future_value_function.py` · `03_lists_and_returns.py` · `04_average_return_function.py` · `05_volatility.py`

Core Python concepts applied to finance: compound returns, future value, volatility calculation from scratch.

---

### 02 — Data Analysis with NumPy & Pandas
`06_numpy_basics.py` · `07_pandas_basics.py` · `08_matplotlib_basics.py`

Real financial data analysis using NumPy arrays, Pandas DataFrames, and Matplotlib visualizations.
Assets analyzed: Eli Lilly (LLY), TSMC (TSM), Schneider Electric (SU.PA).

---

### 03 — Probability & Simulation
`09_distributions.py` · `10_brownian_motion.py`

Probability distributions, normal law, and Geometric Brownian Motion (GBM) for stock price simulation.

---

### 04 — Options Pricing — Black-Scholes
`11_black_scholes.py`

Full implementation of the Black-Scholes model for pricing European call and put options on Eli Lilly.
Includes Greeks: Delta, Gamma, Vega, Theta.

---

### 05 — Portfolio Optimization — Markowitz
`12_markowitz_portfolio.py` · `markowitz_portfolio_optimization.ipynb`

Modern Portfolio Theory applied to real historical data (yfinance).
Monte Carlo simulation of 10,000 portfolios to find the efficient frontier and optimal Sharpe Ratio allocation.

📊 [View Interactive Notebook on nbviewer](https://nbviewer.org/github/matteonicotera/python-finance-basics/blob/main/markowitz_portfolio_optimization.ipynb)

---
